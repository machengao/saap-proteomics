# 学校 Linux 与新队列

## 投递与返回

完整流程的小样本位于项目 `06_validation/saap_skill_r02`。先读其中的《验收与复现.txt》。该包包含已经抽取的真实 MS2 峰、预测响应摘录、历史竞争结果和示例总表；可在 Linux 上离线验收两轮搜索导出到总表的衔接。

本地可管理 skill、样本表、配置和报告。先选择在学校执行的阶段，按 [运行说明](run.md) 冻结清单。发送完整 skill 目录、作业 JSON 和该 JSON 的 inputs 列出的文件，保持相对路径。若数据已经在学校端，用校验值确认并复用，或直接在那里 freeze。代码哈希按字节计算，传输时保留换行与编码。发现与竞争库构建均使用 CPU。

首次接入学校主机，可携带原项目的 `06_validation/saap_skill_r01` 小样本验收包。它含 18 条已导出的扫描记录、搜索配置、参考蛋白摘录和历史预期结果。进入验收包目录，运行 `python check_sample.py --skill /path/to/saap-proteomics --out /path/to/new-check`。脚本用真实入口重建两阶段，校验文件、候选身份、位点事件、质量误差与竞争覆盖。记录主机环境及输出，作为这台机器的验收结果。

- **Linux 虚拟机或远程命令行**。在可写项目工作区用 Python 3.11 及已验收的 pandas、NumPy 环境执行同一个 `run` 命令。用目标机器的 `--root` 绑定数据。输出沿用该次独立运行目录。
- **主机任务或调度器**。将同一条 `run` 命令填进主机任务脚本。记录作业 ID、工作目录、资源配额、stdout/stderr 和退出码。调度器类型由学校实际平台确定。旧项目的 `03_code/MUST_crc2_pilot/crc2.slurm` 绑定 CRC02 和旧配额，可参考提交方式。
- **衔接下一阶段**。检查进程与任务状态，再取回完成清单。完整返回目录可直接用 `verify` 对照本地冻结的 job 验收。大文件留在学校时，在远端执行完整校验，把结果表、完成清单和日志取回，并按其中 SHA256 核对已复制的文件。在同一远端数据根可直接从候选表冻结下一轮竞争库任务。
- **失败恢复**。检查退出码、日志及 `failure.json`，区分输入不符、依赖缺失、执行中断。已完成的上游阶段可独立复用。失败阶段用新的运行目录重试。首轮搜索导出已就绪时，抽样验证直接消费导出表。

在项目约定下，公共 RAW 与参考在数据区，项目下 01_metadata 保存清单，02_config 保存作业，04_work 保存计算产物，05_results 保存交付表，06_validation 保存验收，07_logs 保存日志。后续若迁移 MaxQuant 本体，另验收 .NET、该版本 RAW 读取、临时空间及输出目录。mzML 用于独立谱峰复核。历史两轮 MaxQuant 用 RAW 输入；厂商峰提取可保留在现有可读 RAW 的主机。

## 骨骼肌 TMT 接入

正式队列 PXD011967 的 TMT 6-plex 与五例未标记 DDA 有不同的化学和定量需求。先核对 RAW→批次/分级、批次/通道→供体或公共参考、供体→RNA 的实际 ID 与缺失。再在一个已映射小批次验收肽 N 端及 K 的标签、标记效率、固定 CAM、K 获得/丢失与切点变化，逐项核对前体、碎片和 PTM 竞争的质量计算。验证普通标记肽的 DP 输出和预测模型词表，重校准 NCE 与 RT。

替换鉴定基于混合样本谱，供体量化读取报告离子。登记同位素杂质校正、共分离干扰、低信号、公共参考及跨批归一化。年龄关联以供体为单位。TMT6 参数和质量计算有工程支持，真实数据的回归基准是未标记人类 DDA。全流程在校方可用同一条 pipeline.py 命令，参数、返回码、证据表及缓存按运行编号衔接。
