# 五例工程基准与后续判读

原项目为 `D:/Bioinformatics/Projects/SpectrumFirstFrameshift`，下列目录相对于该根。按运行版本读取 `02_config` 的参数、`05_results` 的结果与 `07_logs` 的完成及校验记录。优先查看 `00_docs/SAAP_项目迁移交接包/方法与代码索引.md` 及 `00_docs/SAAP工作流操作与代码手册_20261111.docx`。复制到其他主机后，用该主机的项目根定位。历史脚本含盘符、旧队列和顶层执行代码，先读源码和参数，再为实际项目准备入口。

| 复核环节 | 既有实现与处理规则 |
|---|---|
| 首轮搜索与 DP 适配 | `03_code/maxquant/prepare_saap_screen.py` 与 `annotate_saap_and_mark_spectra.py`。按 RAW+scan 联结原始谱、PSM、DP 和纯度补算表。PEP 与定位概率取逐扫描记录。五例旧 txt 的 PIF 全零来自关闭 calcPeakProperties，按日志使用已补算值。缺失或不可判定应保留。 |
| 竞争检索 | `03_code/maxquant/analyze_r03_competition.py`。查原扫描、化学形式、来源、位点、普通肽、污染物及可变修饰竞争。按原发现扫描和全部重搜扫描各计一套。对切点改变的候选查引擎原生酶切行为。 |
| 峰与配对丰度 | `03_code/maxquant/review_saap_spectra_abundance.py`。核查位点两侧诊断离子、前体校准、采集窗口和实际可见的碎片电荷。旧 E03 案例遗漏过 y16 的二价匹配，按统一规则审查所有候选与对照。无标记丰度在同样本、同修饰层、共有电荷态比较，查 XIC 的同位素共洗脱与积分，缺失标 NA。 |
| PTM 等竞争解释 | `03_code/saap_evidence_competition_v2/`。同一物理扫描并列候选、基底肽修饰、异位点、普通肽和污染来源，记录质量与位点允许范围。N→D、Q→E 特别核对脱酰胺。替换破坏原修饰位点时重建合法的化学形式。 |
| Prosit/Koina | `03_code/prosit_input_v1/`、`03_code/prosit_full_r01/`。普通肽按 I/L 合并序列拆校准组和留出组。按批校准碰撞能量，按模型和 RAW 校准 RT，用同一采集窗口比较同谱最佳竞争解释，记录模型覆盖、电荷冲突及不可评分。五例 NCE 32 是本批结果。外部端点传输仅在当前任务允许时执行。 |
| 类别错误率 | `03_code/saap_class_fdr_r02/`。从未筛选的引擎结果出发，固定库内对 target/decoy 对称评分，按并列分数块与 (D+1)/T 估计 q，PSM 和肽层分别统计。主搜索、第二肽及预测补充排序各有条件集合。当前缺事件级 q，同一批提出候选再重搜有选择偏倚。 |

冻结五例 PXD034575 的全量历史口径如下。573,549 张 MS2 中有 60,619 张 DP，60,013 条进入候选算法。328 条严格假设对应 320 张原始谱、134 条候选序列、128 个 I/L 合并事件。重搜 31 条优先序列归为 29 个事件。固定竞争库主搜索条件 q≤1% 有 455 个 target PSM、0 条独特肽。这些数用于解释旧项目，不作为新队列的通过条件。机制研究另需评估个体 DNA/RNA 覆盖、变异、编辑和独立实验。
